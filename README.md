# 首飾工作室（P0–P5 完成）

喺瀏覽器入面用 3D 假人設計首飾嘅工具。已完成 P0（3D 假人）、P1（手鏈編輯器）同 P2（腳鏈、臂環、頸鏈）。

## 網上版

**https://octopuscalvin.github.io/A-iue-O/**

- 程式碼放喺私人 repo `octopuscalvin/A-iue-O`。
- 每次 push 去 `main`，GitHub Actions 會自動建置同更新網站，大約要幾分鐘。
- 網上版**包埋 VRM 模型**（作者本人決定公開）。因為網站係公開，任何人都可以下載到個模型檔。想收返，喺 `.github/workflows/pages.yml` 嘅建置步驟加返 `VITE_HAS_VRM: 'false'`，再加一步 `rm -rf dist/models`。
- 用手機打開網上版，可以「加至主畫面」當 App 用。

## 點樣開

第一次要先裝好 [Node.js](https://nodejs.org)（揀 LTS 版本），然後喺呢個資料夾開終端機：

```bash
npm install
```

```bash
npm run dev
```

之後用瀏覽器開 <http://localhost:5173>。同一個 Wi-Fi 嘅手機，可以開終端機顯示嘅 `Network:` 網址。

## 依家做到乜

- **兩種假人**：少女（著基本內衣，預留咗位畀日後加衣服）同基本人台（分節人偶）
- **身材**：160cm、BMI 19.5（纖瘦但健康），手腕 15、腳腕 20、頸 32、頭 54、上臂 23.5cm 都已經校對好
- **三圍調校**：左邊面板有胸圍、腰圍、臀圍滑桿（可以直接打數字），兩種假人都會即時變形，設定會自動記住（`src/body/figure.ts`）
- **少女預設髮型**：紅粉色、齊陰、雙馬尾（`src/body/hair.ts`）
- **360° 旋轉**：滑鼠拖曳旋轉、滾輪縮放、右鍵平移；手機用一隻手指轉、兩隻手指縮放
- **10 個佩戴部位**：頭飾、左右耳、頸、左右上臂、左右手腕、左右腳腕。撳一下鏡頭就會飛過去
- **揀手腕會自動舉起隻手**，方便睇清楚
- **專注模式**：其他身體部分會變透明
- **示範首飾**：手鏈、腳鏈、臂環、頸鏈、耳環、髮箍。用嚟證明首飾會跟住身體郁；吊墜永遠向下垂
- **顯示骨架**：Blender 風格嘅骨頭

## VRM 模型假人

「假人風格」揀「VRM」，再喺「模型」揀用邊個：

- **Sample Manequein**：`public/models/sample-mannequin.vrm`
- **ありさ**：`public/models/arisa.vrm`（作者 Octo，授權容許轉發同修改）

第一次載入大約要 10 至 30 秒。每個模型會分開量度，亦會分開記住自己嘅耳仔 ①②③ 位置。

- **自動縮放到 160cm**，雙手由 T-pose 放低；揀手腕時會舉起隻手。頭髮有物理效果，會跟住郁。
- **外觀**：
  - 「人台質感」：統一啞面質感，冇五官，似真人台。
  - 「原本樣貌」：VRoid 原本嘅樣。
- **衣服同鞋**可以顯示或者收埋。收埋衣服時，頸鏈會改為貼住皮膚。
- **自動量度**：載入時會切開模型，量度手腕、腳腕、上臂同頸嘅真實圍度。
- **首飾尺寸**：
  - 「真人標準」（預設）：用 160cm 女性標準尺寸，零件清單可以直接生產。
  - 「跟模型」：用模型實際量度，戴喺模型上面最貼身。
- 呢個模型係動漫比例，手腕只有約 10.7cm，比真人（約 15cm）幼好多，所以跟模型做嘅首飾，真人會戴唔落。
- 頸鏈會根據模型嘅身體表面（膊頭高度、心口前面）自動垂落。
- **加新 VRM 模型**：將 .vrm 檔放入 `public/models/`，再喺 `src/body/vrmModels.ts` 加一行。模型要用 VRM 1.0 格式、人形骨架。
- 暫時唔支援：三圍調校、專注模式、顯示骨架（呢幾個功能只限程式生成嘅假人）。

> 授權：呢個 VRM 嘅授權設定係「只限作者、非牟利、唔准修改、唔准轉發」。如果將來要商業使用，請喺 VRoid Studio 重新匯出，並改成容許商業使用嘅授權。

## 首飾編輯器（P1 + P2）

撳手腕、腳腕、上臂或者頸，右邊就會出現編輯面板。手鏈、腳鏈、臂環、頸鏈都係用同一套方法：

- **頸鏈**：揀長度款式（頸圈 34cm、鎖骨 42cm、公主 47cm、長款 55cm），條鏈會繞過後頸、喺前面自然垂落，並且貼住身體（調三圍都唔會穿過心口）。
- **腳鏈**：鬆緊分貼身、舒適、垂墜。
- **臂環**：多咗「開口臂環」（硬身開口款）。
- **吊墜識得晃動**：假人郁手時，吊墜會好似真嘅一樣擺幾下先停。

編輯步驟：

1. **底座**：揀 O字鏈、珠串、手鐲、絲絨繩或者蕾絲帶，再揀材質、粗幼同鬆緊（貼身、舒適、寬鬆）。內圈長度會跟手腕自動計；手鐲會自動加大，確保套得過手掌。
2. **配件**：有心心、星星、月亮、花、蝴蝶結、貓爪、雲朵、圓珠 8 款。撳一下就會加入；喺 3D 入面直接拖動可以改位置，亦可以改材質同大小。
   - 吊墜會受地心吸力向下垂，唔會插入手腕。
   - 圓珠喺鏈、珠串同繩上面會直接穿入去。
3. **零件清單**：每件零件嘅規格、數量、材質同估算重量，可以交俾師傅用。
   - 如果配件太密、太重，或者組合唔合理，都會出提示。
4. **其他功能**：複製去另一隻手（位置會自動左右對調）、匯出設計檔（JSON）、刪除設計。設計會自動儲存喺瀏覽器。

## 底座款式（手鏈 / 腳鏈 / 臂環 / 頸鏈）

揀咗部位之後，「① 底座」分四組，每款都有自己嘅選項：

| 組 | 款式 | 選項 |
|---|---|---|
| 鏈 | **金屬鏈** | 鏈款：O字鏈、側身鏈、費加洛、盒仔鏈、波珠鏈、蛇骨鏈、扭繩鏈 |
| 鏈 | **名牌鏈** | 刻字（英文 / 數字）、名牌長度 |
| 鏈 | **鑽石鏈**（網球手鏈） | 寶石：白鑽、粉紅鑽、海藍、祖母綠、紅寶石、紫水晶 |
| 珠 | **珠串** | 珠形：圓珠、切面水晶、方珠、扁珠；**字母珠**（例如 ARISA） |
| 珠 | **螺旋手鐲**（記憶鋼線） | 圈數、珠色 |
| 硬身 | **手鐲** | 粗度 |
| 硬身 | **硬膠手環**（亞克力 / 樹脂） | 闊度、表面：光面、坑紋、切面、扭紋；可以揀閃粉膠 |
| 硬身 | **開口手鐲**（C 形） | 闊度、表面：光面、錘紋、坑紋、扭紋 |
| 繩帶 | **矽膠手環** | 闊度、凹字 |
| 繩帶 | **絲絨繩** | 繩粗 |
| 繩帶 | **編織手繩**（友誼手繩） | 三股辮 / 扭繩、每股顏色、抽繩結 |
| 繩帶 | **皮繩多圈** | 圈數（1–3）、按扣 |
| 繩帶 | **皮帶扣手帶** | 闊度、皮帶扣 |
| 繩帶 | **髮圈手圈** | 粗度 |
| 繩帶 | **蕾絲帶** | 闊度 |

- 硬膠手環、開口手鐲、矽膠手環、皮帶扣手帶上面嘅配件會**黏喺表面**，其他款式就**吊住**。
- 每款都有自己嘅零件清單、價錢（「報價設定」可以改）同生產藍圖組裝步驟。
- 新材質：矽膠、閃粉膠、棉繩、皮革、寶石。

## 耳環同頭飾（P3）

- **耳環**（揀「左耳」/「右耳」）：
  - **耳釘**：撳一件配件，佢就係耳釘面。
  - **耳圈**：可以調直徑同線徑，配件掛喺圈上面，可以調角度。
  - **吊墜耳環**：法式耳鈎加幼鏈，配件由上至下一件接一件吊落去。
  - **耳骨夾**：唔使穿耳，開口夾夾喺耳骨邊，可以調直徑同線徑，配件吊喺外面。
  - **位置**：① 耳珠（預設）、② 耳珠上緣、③ 耳骨。耳骨夾預設係 ③。揀 ③ 做耳釘、耳圈或者吊墜時，會提示要另外穿耳骨洞。
    - 預設位置跟一般穿耳指引：① 耳珠肉墊正中；② 喺 ① 上面約 7mm、略向後；③ 耳朵上半部外緣。
    - 揀耳仔時，耳仔上面會顯示 ①②③ 小標記，撳標記就用嗰個位置。
    - **自己設定**：撳「✎ 撳耳仔設定」，再喺 3D 入面撳耳仔上面你想要嘅位置。兩隻耳會一齊改（左右對稱），會自動記住；「還原預設」就變返預設。程式假人同 VRM 嘅設定分開記住。
  - 「複製去右耳 / 左耳」一鍵做成一對。
  - VRM 模型揀耳仔時，頭髮會暫時收埋，等你睇到耳環。
- **頭飾**（揀「頭飾」）：
  - **髮箍**：由左耳上面跨過頭頂去到右耳，長度跟頭形自動計。
  - **髮夾**：50mm 彈簧髮夾。「夾喺」調由左耳上面、頭頂到右耳上面嘅位置；「前後」調向額頭或者向後腦移動（±35mm），髮夾會跟住頭形轉角度。
  - 配件會黏喺上面，可以調位置（%）。
  - 底座可以揀金屬、塑膠或者布料。
- 喺 3D 入面撳配件，就可以揀中佢嚟改。

## 作品、報價同生產藍圖（P4）

3D 畫面左下角有三個掣：

- **📁 作品**
  - **儲存**：將而家所有部位嘅首飾連假人設定，存做一個有名嘅作品。設計本身亦會自動儲存。
  - **載入 / 刪除**：載入其他作品之前，會先自動備份目前設計（最多保留 5 個自動備份）。
  - **複製分享連結**：成套作品會放喺網址入面，對方開條連結就會問佢要唔要載入。唔會上傳去任何伺服器。
  - **匯出 / 匯入檔案**：成套作品（.json）。編輯器匯出嘅單件設計檔亦可以匯入。
- **📄 生產藍圖**：喺 App 入面開一份文件，可以「列印 / 另存 PDF」或者下載。內容包括：
  - 3D 預覽圖、全套成本同建議售價。
  - 每件首飾嘅 **1:1 展開圖**（mm），標明每件配件離起點幾多 mm。耳環圖就放大 2 倍。
  - 自動生成嘅**組裝步驟**。
  - 零件清單：規格、物料、數量、重量、成本。
  - 列印時要揀「實際大小 / 100%」，圖則先係 1:1。
- **💲 報價設定**：每樣零件嘅單價（港幣）、人工同售價倍數都可以改，改完所有報價會即時更新。預設價錢只係參考。
- 每個編輯器嘅「零件清單同報價」都會顯示材料、人工、成本同建議售價。

## 衣服 DLC 同手機 App（P5）

- **衣櫃**：假人風格揀「少女」，左邊會出現「衣櫃」。
  - 第一個 DLC 包「基本衣櫃（免費）」有：連身長裙、T 恤、百褶短裙、牛仔短褲、過膝長襪、短襪、瑪莉珍鞋。每件都有幾隻顏色揀。
  - 連身裙同上衣 / 下裝只可以二揀一。
  - 衣服會跟三圍變大變細，頸鏈會自動貼住件衫。
  - 作品會連埋衣服一齊儲存同分享。
  - 加新衣服：喺 `src/body/outfits.ts` 嘅 `OUTFITS` 加一項就得。
- **手機**：
  - 網站可以「加至主畫面」，當 App 咁用，亦支援離線使用（PWA）。
  - `android/`、`ios/` 已經係 Capacitor App 項目。做法見 [docs/MOBILE.md](docs/MOBILE.md)。
