# 首飾工作室：藍圖

## 目標
1. 喺瀏覽器、iOS 同 Android 上面，用 3D 假人設計首飾
2. 設計要比一般換裝遊戲更仔細，尺寸要準確到毫米
3. 每件設計都可以匯出一份**生產藍圖**，畀師傅照住大量生產

## 系統分三層

```
假人層：3D 人體 + 骨架 + 掛點 + 衣物層（DLC）
   ↓ 首飾跟住掛點戴上身
結構層：首飾 = 底座（鏈、繩、帶、圈）+ 配件（掛喺底座某個位置）+ 扣頭
   ↓ 每件組件套用材質
材質層：金屬、塑膠、布料，各有預設
```

## 技術

| 部分 | 選擇 |
|---|---|
| 網頁 | React + TypeScript + Vite |
| 3D | Three.js（配 React Three Fiber 同 drei） |
| 狀態 | Zustand |
| 手機 App | Capacitor：將同一套網頁包裝成 iOS 同 Android App |
| 正式假人模型 | Blender 製作，匯出 GLB；骨頭名稱要同 `skeleton.ts` 一致 |

## 假人

- 兩種風格共用同一副骨架同同一套掛點，所以首飾兩邊都戴得。
- P0 嘅假人係用程式即時生成嘅。之後可以喺 Blender 做（或者外判做）一個精緻嘅少女 GLB 模型；只要骨頭名稱對得上，就可以直接替換。
- **衣服 DLC**：每件衣服都係一層「貼身外殼」，即係由身體形狀放大少少（內衣已經用咗呢個方法）。長裙之類嘅衣服再加布料模擬。每件衣服用一份資料檔定義，下載咗就加入衣櫃。

## 首飾資料格式（存檔、分享、生產都用同一份）

```json
{
  "id": "bracelet-001",
  "zone": "wristL",
  "base": { "type": "chain_cable", "material": "gold_polished", "length_mm": 172, "wire_mm": 0.8 },
  "charms": [
    { "shape": "heart", "material": "jelly_pink", "t": 0.25, "size_mm": 10, "ring": "jump_4mm" }
  ],
  "clasp": "lobster_10mm"
}
```

`t` 係配件喺底座上面嘅位置：0 係起點，1 係終點。

## 生產藍圖（俾師傅）
- 每件首飾一頁：正面、側面、頂視圖；1:1 尺寸圖；全部長度以 mm 標示
- 零件清單：零件名稱、物料、數量、尺寸、供應商編號（之後建立零件目錄）
- 估算重量同成本
- 組裝次序：邊件零件用邊個扣環連住邊度
- 匯出格式：PDF（畀師傅睇）、CSV（零件清單）、STL / GLB（3D 打印或者開模）
